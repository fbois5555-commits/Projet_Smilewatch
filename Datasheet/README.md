# Datasheet — Fiches Techniques Composants

Ce dossier centralise les datasheets officielles des composants critiques utilisés sur la SmileWatch :

- **MCU & RF** : `STM32WB55`, `MLPF-WB-02D3`, antenne `Johanson 2450AT`.
- **Capteurs & Actionneurs** : `LSM6DSOX` (IMU + MLC), `MAX30101` (PPG/SpO2), `TMP117` (température), `VEML6030` (luminosité), `DRV2605L` (haptique), `CH1115` (OLED).
- **Énergie & Charge** : `BQ51003` (Qi RX), `BQ24040` (chargeur Li-Ion), `TPS61023` (boost +5V), `TPS7A02` (LDO), `AP9101C` (protection batterie), `LIR3048`.
- **Horlogerie** : `Miyota 2035`.
